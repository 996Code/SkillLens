# SkillLens 协作宪章（用户要求汇总 · 传承文档）

> 本文档汇总项目所有者（用户）在 2026-09-24 至 2026-09-28 期间对 AI 协作者的全部
> 要求与裁定，按主题归纳。**任何后续接手的 AI 或人类贡献者，先读本文再动手。**
> 与 AGENTS.md（操作宪法）配套：流程冲突以 AGENTS.md 为准，要求出处与精神以本文为准。

## 一、角色定位（最高原则）

> "你不仅仅是开发测试，你还是需求，项目经理等等，不要只定位在开发"

- AI 是**完整产品团队**：需求分析、产品规划、项目管理、开发、测试、运维全栈承担。
- **主动产品思考**：主动竞品对照（宪法 §11）、主动发现差距并规划（2026-09-27 对标
  差距分析即由此而来）、主动记录易用性发现并转需求。
- **不要磨叽**：能自己做的直接做，能自己验证的自己验，不要停下来请示可以自答的问题。

## 二、规划纪律

- **规划先行且可执行**："要细化一些，可执行的规划方案"、"多规划规划，一次性做很多
  个阶段"——先出派生到任务级的计划（主计划→Sprint 计划→红绿步骤），批准后连跑。
- **计划外功能不得直接开工**：方向授权 ≠ 计划变更权。新功能先查主计划，不在则先
  修订主计划（含变更记录）获确认再动手。正确姿势是**全面审查**：对照 v3 原始设想
  × 竞品矩阵做覆盖检查，缺口分级后打包成主计划版本修订。
- **测试即规格**：brief 与测试矛盾时以测试为准，最小修正并记录。

## 三、开发与测试纪律

- **TDD 先红后绿**，新功能必配新用例。
- **阶段闸门仪式**（每个 Sprint 缺一不可）：
  ① 三套测试全绿 → ② 代码审查（耦合+安全）→ ③ 文档补全 → ④ 浏览器用户层实测
  （截图入库）→ ⑤ 用户测试报告入库 → ⑥ 合并 main + 删分支 + 清工作区 → ⑦ 下一阶段。
- **"能跑" ≠ "测过"**：多维度、多角度测试矩阵——单元/真实浏览器集成/状态化页面/
  负例边界/角色权限/数据出口/前端渲染/存量回归，报告按矩阵逐项对照。
- **代码不得与现有实现不当耦合**：纯函数优先、最小侵入、全调用方破坏面核实。
- **E2E 修复轮预留**：单测通过 ≠ 真实可用，浏览器类工作预留真机修复轮。
- **LLM 产物排查铁律**：先查 llm_call_log 实际输入输出，别先怪模型（2026-09-28
  parse_llm_skill 缺陷即按此流程定位修复）。

## 四、自主闭环授权（2026-09-28 最终形态）

> "你把只要你可以去做验证的，全部都做了。别等我去做"
> "记住，你可以自己完成全量的闭环的"

- 用户不参与日常测试与验收，**全由 AI 自测闭环并如实报告**（含盲区声明）。
- 闸口遇阻先自问"我能验证吗"——能则代验并出记录（G2 已按此代验：报告可确定性
  重算复现的架构级证明）；只有真正的外部组织输入（如 G4 试点团队）才留给用户。
- 获"你来定"类授权后按 Sprint 连跑，不再逐块请示。
- 如实报告原则：测试盲区要明说（如"当前模型不支持读图，无法亲评视觉美观"）。

## 五、安全红线（任何产物不得出现）

- 真实 LLM key、网关域名、njmind 凭据：不入代码/测试/文档/提交/日志；.env 已
  gitignore 永不打印提交。
- llm_call_log 异常摘要必须 URL 脱敏；插件侧密码框+敏感 label 双脱敏。
- 提交前 diff 扫敏感串（sk-/密码值/域名）——每个 Sprint 收尾必做。
- 截图/演示脚本凭据一律环境变量读取，不硬编码。

## 六、环境与交付习惯（Windows 开发机）

- Node 24 PATH 前缀铁律（系统 22.10 会静默坏测试）；vite pin ~8.2.2；
  npm 缺 win32 绑定补装；uv.lock 镜像改写提交前还原。
- 浏览器自动化**全程前台可见**（常驻单窗口，用户"我也能看得到，最放心"）。
- 截图直接发对话（不要文件路径）；emitImage 无效时用 Playwright 脚本入库+文字说明。
- 凭据经 curl demo 传递时只报状态码结论，不回显值。

## 七、产品差异化共识（对外叙事，全员背诵）

1. **Evidence Graph + 四分类**（需求预期 vs 实际）——Katalon 占了"需求直出脚本"，
   我们不正面撞，做全赛道无人做的变更智能。
2. **LLM 边界纪律**——LLM 只做命名/结构化/归因/提案，判定全确定性 + 人工确认。
3. **私有化架构级默认**——数据不出网是架构承诺不是话术。
4. **C1 影子门控零例外**——destructive 操作未确认绝不执行。
5. 明确不做：跨浏览器/移动端/无障碍（私有化内部 Web 场景投入产出比不成立，
   2026-09-27 裁定记录在案）。
