# S39：流程图基座重构——图工作台（图优先导航）

> 2026-09-29。触发：用户"菜单是有了，但还是以前的味道，不是以流程图为底座
> 打造的系统"+"先想清楚问题在哪"。诊断：此前把流程图当**视图控件**贴在
> 实体页面上，系统骨架仍是"侧边栏→实体列表页"。本块改为**图优先导航**。

## 架构转变

```
旧：侧边栏（8 实体菜单）→ 实体页面（列表/表格）→ 图是局部挂件
新：图工作台（唯一主界面）→ 打开即图 → 导航=图上下钻 → 列表降级为图入口
```

## 交付

### 图工作台壳（GraphWorkspace.vue，/graph 全幅）

- **左：图导航树**——系统总览 → 流水线 → 操作流程（按系统标注）→ 其他
  （仪表盘/报告/审计/编排深链）；当前流程高亮
- **中：当前层级的图**（嵌套路由 RouterView）
- 首页 `/` 重定向 `/graph`（不再是仪表盘）；/graph 路由族隐藏主侧栏+限宽壳

### 系统总览（GraphOverview.vue，/graph）

- 流水线图卡片（流程×N → 批量测试 → 汇总的图形态 + 系统徽标）
- 操作流程按**目标系统分组**的图入口卡片（页面→操作→断言）

### 操作流程图（SkillGraphView.vue，/graph/skill/:id）

- GET /skills/{id}/flow（build_skill_flow）：骨架签名拆解为
  page → action×N（kind+label+APIs）→ assert×N 节点链
- FlowGraph 组件渲染；底部最近执行（下钻执行图 /replay-runs/:id）

### 下钻链（本块打通的主干道）

```
系统总览（图卡片）→ 点流程卡片 → 流程图（8 节点）→ 点最近执行 → 执行图
```

## 真机验证

- 首页 `/` → /graph：左树 68 项、流水线区+流程区上屏
- 点流程卡片 → /graph/skill/65：流程图 8 节点渲染
