1. **新增块 M「链路审计」**（4 点）：会话链下钻 / 证据图视图 / LLM 调用日志 / 噪声决策视图——排 S11 前
2. **新增块 N「学习深化」**（5 点）：新功能增量发现 / Requirement 先验对齐 / Outcome 层1 采集 / 层4-5 细化 / Active Probing 设计评估——排 M2 出口前后
3. **块 L 补注**：分层双维度（UI 版本化 + 跨系统槽位）
4. **S17 补注**：PII 规则配置化明确入安全审计
5. **S11 验收增观察项**：第一次真实变更时，记录系统对新功能的发现行为（G-2 天然实验场）
